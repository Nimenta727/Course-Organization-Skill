# FAQ / 常见问题

### 这是能一键上传 PPT、自动生成整门课程的系统吗？
**不是。** v0.2.4 是可移植 Agent Skill + Python 离线校验器。实际文件解析、OCR、网页检索和教材创作取决于宿主 Agent 的工具及使用许可。本仓库 CLI 不会执行这些操作。

### 为什么不按概念拆成很多独立文件？
学生需要从头连贯地学习一节课，也要能在复习时快速定位知识。每节课只生成一篇完整讲义，包含解释、示例、作业、答案和复习速览。内部证据映射可以细分，不应让学生追着中间产物跳转。

### 为什么九个章节和五道作业这么严格？
这是为避免敷衍而设置的**内容最低验收底线**：重要知识点需要充分讲解、例题和检验；作业要有层次和答案推理。字数不足会被挡住，但字数够不代表已经学术正确或适合学生；独立审阅仍必需。

### 必须有七个真实子智能体才能使用吗？
可以先创建、试读或私人讨论内容；但**要宣称“通过独立严格审核”**，七种审阅职责必须由真实独立子智能体或独立人类履行。CLI 的 \`review-plan\` 只生成任务，\`review-gate\` 只验证报告字段和哈希；它们不会启动模型，也不能验证审阅行为真的发生。没有独立审核就保持 \`REVIEW_PENDING\`。

### 老师写的每个字都需要出现在学生正文吗？
不是。教师教学顺序、强调、误区、板书中跳过的推导需要在**私有证据映射**里被核查覆盖；学生正文用合法、准确、独立的语言讲透相应知识。独创文本、图形和受保护题目是否能复制取决于具体授权。不能假定“AI 改写了一次”就消除版权风险。

### 老师的错误是不是有意设计的？
除非老师或实际资料明确证明，不能知道。只解释观察到的错误类型、为什么错、怎么修正；“老师可能想训练什么”属于内部假设，不能当事实写给学生。

### 能自动查大学教材和正式考题吗？
\`research-plan\` 只生成待查关键词并标记 \`NOT_SEARCHED\`。配备授权网页工具的 Agent 可以实际查验官方来源；请记录网页日期、可靠性与再使用权。公开发布的正式考试题也不必然允许全文转载，通常应提供原站链接并自创练习题。

### 为什么 \`audit\` 是 BLOCK？
虚构示例故意没授予公开传播权。公开前必须有人核对具体资料、图片、题目、许可与学生隐私；自动审核只是一个保守的声明门禁。BLOCK 是安全的预期行为，不能当程序故障。

### 能用在哪些学科？
编程、数学、自然科学、人文、语言、经济与工程都有专门的学科 profile。九个学生阅读章节相同，但具体推导、举例、作业类型和证明方式随学科调整，不会把 C 语言内存追踪强行用于文学课。

### 发布文件中为什么有 ZIP 和 wheel？
**Skill ZIP** 是给 AI Agent 安装的完整教学指令与模板；**wheel** 是给 Python 安装的离线 CLI。二者独立。GitHub 源码压缩包包含全部仓库和测试，最适合开发者。

### 旧版本材料在哪里？
旧版 README、发布草案和任何删除的现行文档保存在 **Git 提交历史**中；不在当前树里放冗余的 \`legacy/\` 或 \`archive/\`。长期开发变更记录始终保留在 [docs/routine](routine/)。

**English summary:** The project is a preview Agent Skill with an offline validator, not an autonomous ingestion service. Student chapters are substantial and single-file. Independent audits are real only when independent agents/humans actually review them. Metadata PASS is not legal permission.
