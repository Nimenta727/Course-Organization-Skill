# v0.2.2 Preview — 强制深度讲义、作业与独立审阅

**Preview version.** Student-facing output now follows a deep, readable nine-section chapter model, rather than producer-facing teacher-evidence reports.

## Added
- New student-edition.md authoring contract, assignment-module.md and subagent-review.md.
- One complete beginner/revision lesson with at least two fully explained K topics, a worked example, five tiered tasks and detailed paired answers.
- CLI student-check: deterministic chapter depth, knowledge-unit, assignment-tier, answer alignment and placeholder/privacy-heading checks.
- CLI review-gate: seven distinct independent reviewer declarations, roles, per-lesson SHA-256 freshness and reviewer separation.
- CLI ready: combines structure, student-depth and independent review-report gates.
- Negative regression tests for shallow prose, one-line topics, missing tier/answers, leaked producer headings, self-signed or stale review reports.

## Important limits
The CLI **does not run or create subagents**. The host Agent must actually delegate seven independent reviewers, or humans must review. Sequential self-review by the author is insufficient, and a metadata PASS alone cannot establish that a review actually happened. Any unavailable review means REVIEW_PENDING.

Teacher course materials are private research inputs; no original teacher slides, assignments, student data or protected exam content have been copied into this release. The example is independently authored. Public release of any course still needs explicit human rights and privacy review.

## Install and test
Clone tagged sources for the full Skill, or install optional local CLI: python -m pip install -e .
Then run: course-org validate examples/sample-course; course-org student-check examples/sample-course; python -m unittest discover -s tests -v.

**English:** Strict learner-facing authoring and per-assignment solutions are now mandatory, with metadata/hash gates for seven genuinely independent subagent/human reviews. This release ships **review protocols and validators**, not an agent-orchestration runtime or legal clearance.
