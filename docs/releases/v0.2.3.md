# v0.2.3 Preview — 严格逐知识点、逐作业独立审核

## What changed / 本轮增强
- New review-plan command generates seven role-specific tasks for each lesson with required knowledge K and homework Q targets plus SHA-256.
- It deliberately sets review_executed to false and status to REVIEW_PENDING. This tool does **not** launch child agents or certify any review.
- The review-gate now blocks reports omitting required K/Q checks, with short generic evidence, author/reviewer identity conflict, stale lesson digests, or private review reports inside a Git worktree.
- Every assignment_integrity report must include question_checks for **every** Q: blind_solved, compared_to_solution, status and meaningful reasoning. The reviewer first solves without the drafted answers, then compares results.
- student-check flags unusually similar task statements (e.g. rewriting the same exercise by changing only numbers). Semantic independent review still required.
- Regression tests cover missing K/Q audit items, each assignment requiring independent verification, duplicate homework and private report location.

## Usage / 使用
Install the optional CLI from this repository with Python 3.10+. Then use:

    course-org validate examples/sample-course
    course-org student-check examples/sample-course
    course-org review-plan examples/sample-course
    course-org review-gate YOUR_COURSE --report /private/independent-review.json
    course-org ready YOUR_COURSE --report /private/independent-review.json

The fictional sample has NO genuine independent reviewer report, so it is not considered independently reviewed. A test that passes a synthetic report schema is NOT proof that seven external subagents were used.

## Current capability boundary
- No native subagent executor or web crawler is shipped in the CLI.
- Real reviews require independent agents supported by the host or independent humans, under proper permissions.
- No semantic guarantee of pedagogical truth, student readability, exam correctness or copyright clearance from deterministic metadata checks.
- Public publication is subject to a separate rights/privacy gate and explicit human approval.

This is a pre-release, not a turnkey document-ingestion or course-writing application.
