# v0.2.4 Preview — Course Organization Skill

**2026-11-21 · Pre-release · Teacher-led, student-first course learning**

## 本次更新 / Highlights

**以学生阅读为中心：** 一课一篇完整讲义，统一九个主要章节，覆盖新手需要的详细推导、完整原创例题、错误修正、深入理解、复习速览和全部作业答案；不把教师意图假设或内部权限/审核报告混入学生正文。

**强制作业与质量底线：** 每课至少 2 道基础、2 道应用、1 道挑战。每题需要明确任务、提交要求、验收、提示和推理型答案。离线检查器拒绝浅显的一句话解释、缺少答案和高度重复的题目；实质教学效果还需要独立复核。

**教师主线 + 版权边界：** 内部结构记录老师实际可验证的课次顺序、板书跳步、强调和错误案例；发布候选内容独立撰写、谨慎引用。未经许可的原始讲义、学生资料、真题不可自动公开，元数据审计不能提供绝对法律保证。

**七角色独立审核：** 逐 K 知识点、逐 Q 作业审阅计划和哈希报告门禁已具备，**但 CLI 并不会真正启动子智能体**。必须由真实独立子智能体或人工完成；否则返回 REVIEW_PENDING。

**完整的公开发行物：** 本次与之前最大的工程改进是新增完整 Skill ZIP，另附单独的 CLI wheel 和 SHA-256 校验文件，修复过去只给 wheel 而没有教学 Skill 安装包的歧义。README、安装指南、示例、打包和测试流程均按本版本统一。

## 下载与安装 / Artifacts

1. **\`course-organization-skill-v0.2.4.zip\`** — 完整 Agent Skill，解压后有 \`course-organization/SKILL.md\`、\`references/\`、\`assets/\`、双语 README 与 MIT LICENSE。将目录放进支持的 Agent Skills 路径，或让 Agent 明确读取 SKILL.md。
2. **\`course_organization_skill-0.2.4-*.whl\`** — 可选 Python CLI，仅提供 \`course-org\` 命令，不能代替完整 Skill。
3. **\`SHA256SUMS.txt\`** — 完整 ZIP 与 wheel 哈希核对。
4. GitHub 自动 Source code ZIP/tar.gz — 整个仓库（含代码、测试、文档），适合开发。

详见 [Quick start](../QUICKSTART.md)、[Installation](../INSTALLATION.md)、[Usage](../USAGE.md)。

## 真正实现的能力 / Implemented

- Agent Skill 规范、多个学科差异化规则、课程模板与完整原创编程示例。
- 文件元数据扫描、课程与学生知识密度检查、分层作业和答案配对。
- 私有教师证据与外部资源登记的元数据规则。
- 七角色审阅任务清单、逐 K/Q 字段验证、SHA 新鲜度检查。
- 离线权威资料查询计划 \`NOT_SEARCHED\`。
- 英文/中文 README、使用与开发文档、GitHub Issues/PR 模板、自动测试、版本发行与可复现 Skill ZIP 打包。

## 不包含 / Not shipped

- 自动解析任意 PPT/PDF/DOCX 课程正文或 OCR 课件。
- 无需权限的网页检索、自动抓取正式考试试卷。
- 内置大模型、真实子智能体执行器或无需人工的完整教学审核。
- 任何“版权零风险”认证或教师原文件的公开传播许可。

## 安全验收 / Checks

~~~bash
python -m pip install -e .
python -m unittest discover -s tests -v
course-org validate examples/sample-course
course-org student-check examples/sample-course
course-org research-plan examples/sample-course
course-org review-plan examples/sample-course
python scripts/package_skill.py
~~~

示例的 \`course-org audit examples/sample-course\` 必须因尚未获得公开发布许可而 BLOCK。实际 CI、ZIP/wheel 版本和 Release tag 应在 GitHub 页面核对。

**English:** Preview v0.2.4 consolidates the current, student-first Skill; adds a reproducible complete Skill ZIP alongside the CLI wheel and checksums; retains strict tiered homework and seven-role offline review declarations. It does not autonomously execute reviewers, ingest arbitrary teacher files or grant publication rights.
