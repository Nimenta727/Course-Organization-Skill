# v0.2.1 Preview — 发布包装与文档整理

**2026-11-20 · Pre-release**

## 新增 / Added

- 全新详尽中文 README 与实质对应的英文 README。
- 安装与集成、快速开始、使用指南、FAQ、开发者指南和发布检查清单。
- CONTRIBUTING、CODE_OF_CONDUCT、SECURITY、CITATION、CHANGELOG 和 Issue/PR 模板。
- 统一 GitHub Topics 与 Issue 标签建议，提供可由维护者手动执行的标签同步流程。
- Python/Skill 校验与发布 CI 的可运行配置（需在 Actions 中实际验证）。
- 将版本元数据与文档统一为 v0.2.1 Preview。

## 保留的主要能力 / Existing foundations

- 教师课堂主线、板书与可能错误示范的保真协议。
- 一课一文，初学/复习双路径和不同学科规范。
- 权威资料检索的 Agent 工作流（取决于实际联网工具及授权）。
- CLI 文件元数据扫描、课程结构校验、发布声明审计、教师证据台账校验和离线研究查询计划。
- 私有资料默认不公开和人工版权审核要求。

## 明确不在此版本中 / Not shipped

- PDF/PPTX/DOCX 正文自动提取、OCR 或大规模课程重建引擎。
- 通过 CLI 自动联网搜索、真题下载、学生学习管理、课程网站。
- 完整版权判定、语义抄袭识别或法律上的零侵权保证。
- 自动公开发布教师受版权保护的课件、录音、习题。

## 安装 / Installation

用于 Agent Skill 的完整目录：从本仓库的对应 tag 下载 source ZIP 或 git clone。Python CLI（可选）：\`python -m pip install -e .\`。

GitHub Release 如附带 wheel，**仅包含本地 CLI 软件包**，不等于完整 Skill 的模板与 references。

## 安全发布 / Safe release

先检查许可证、来源授权、学术事实、个人信息，跑完单元测试并确认 \`audit\` 默认阻断示例的公开发布，再执行手动预发布。详细步骤见 [RELEASE.md](../RELEASE.md)。
