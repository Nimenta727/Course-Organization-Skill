# 2026-11-21 — 学生可读性、知识密度、分层作业与子智能体强制审计

## 变更范围
- 新增 student-edition.md：面向学生的完整讲义规范，确定一课一文、九大核心章节、知识点五维讲清、完整案例和复习速览，并加入强制实质内容密度底线。
- 新增 assignment-module.md：最低 2 道基础、2 道应用、1 道挑战的完整作业模块，全部要求任务、交付物、验收、提示和分步答案。
- 新增 subagent-review.md：七个独立角色严格审核教师覆盖、初学可读性、学科准确性、作业正确性、复习有效性、权利隐私及对抗性问题。
- 将“教师意图”和“内部审计”等信息留在生产环境而不是学生讲义中；真实老师上传的资料仅用于学习教学方法，没有写入 GitHub。

## 质量原则
- 一个知识点不能只写一句话；必须解释为什么、直觉、准确规则、推演、自检。
- 自动字数/标题检查只是底线；禁止灌水，必须真正独立的学科、教学、作业审阅。
- 若宿主支持子智能体，需真正委派；若不支持，需独立人工审核并如实标记，不得伪造审计。
- 章节修改后原审核结果因 SHA-256 不匹配立即失效；版权审核另行执行，默认从严。

## 验证与下一步
- 后续同一版本将同步增加 CLI 质量检查与审阅门禁、单元测试、详细课程模板和原创示例。
- 最终测试结果以 GitHub Actions 真实执行记录为准；未获验证的功能不能宣称已通过。
