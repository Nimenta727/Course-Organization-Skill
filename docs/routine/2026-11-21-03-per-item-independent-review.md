# 2026-11-21 — v0.2.3 逐知识点/逐作业强制独立审阅

## 本次修改与行为
- 新增 src/course_org/reviewer_tasks.py：为每课生成七类审核任务、完整 K/Q 检查项及当前 SHA-256；结果明确声明 review_executed=false、REVIEW_PENDING，不伪装实际子智能体。
- 修改 student_quality.py：角色审阅必须覆盖所要求的 K 知识点和 Q 作业；作业审阅者必须每题提交盲解、核对、结论与实质性理由；报告不能留在 Git worktree，章节变动使旧哈希失效。
- 新增作业题干高相似度检查；不会因为填满字数或只改数字就自动视为高质量。
- CLI 新增 review-plan COURSE_DIR 输出机器可读的委派任务清单。
- 测试补充：漏审知识点/作业、空泛审阅、过期报告、重复题目及审阅报告私有路径。
- 同步 SKILL.md、教学/作业/子智能体/来源数据规范、双语 README、使用/开发/发布说明、变更日志与项目版本 v0.2.3。

## 限制
- 当前无真正的跨模型子智能体委派执行器；可由有实际委派功能的 Agent 使用该任务清单，或由独立人工审核。
- 静态审计只能核查声明及哈希，不能证明是否存在凑字数、事实错误、真实版权许可或真正独立审阅。人工/独立审核依然是硬性要求。
- 未上传任何老师课件原件或学生个人信息。
