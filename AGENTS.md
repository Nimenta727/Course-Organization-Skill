# Instructions for coding agents

Read SKILL.md for course organization tasks. For repository engineering work:
- Preserve lesson-centered architecture and private-by-default rights policy.
- Never commit educator originals, copyrighted course packs, student data or local source manifests.
- Use original language, not copied prompts/templates from external projects.
- Work non-destructively and explain planned changes before bulk rewrites.
- Add automated tests for changed behavior where possible.
- After EVERY GitHub modification, add a dated docs/routine/YYYY-MM-DD-<summary>.md entry with what changed, tests actually run, blockers, and the next step.
- Keep README.md and README_EN.md aligned when functionality changes.
- Copyright and privacy vetoes override feature convenience. No audit can promise zero legal risk.
