# Pedagogical decision matrix / 教学方法矩阵

Use a *selective* strategy; a single course need not force every framework into every lesson.

| Framework | When useful | Operational requirement |
| --- | --- | --- |
| ADDIE | Full course lifecycle | Intake needs, design, develop, pilot/implement, gather feedback/evaluate |
| Backward design / UbD | All curriculum plans | Outcome -> observable evidence -> lesson activities |
| Constructive alignment | All courses | Each LO maps to ACT and A; mismatch is reported |
| Revised Bloom taxonomy | Design cognitive progression | Vary from remember/understand to apply/analyze/evaluate/create as appropriate |
| Merrill first principles | Procedural / skill subjects | Problem-centered activation, demonstration, application, integration |
| 5E inquiry | Science and exploration | Engage, explore, explain, elaborate, evaluate; do not force on all topics |
| Project-based learning | Integrative work | Authentic driving question, iterative artifacts and feedback |
| Formative assessment | Every lesson | Early diagnostic, quick check and targeted feedback |
| Mastery learning | Skill progression | Transparent criteria, corrective practice, reassessment opportunities |
| Retrieval and spacing | Retention | Short no-notes retrieval and spaced revisits across lessons |
| Interleaving | Confusable skills | Mix related concept types *after* foundations are established |
| Worked examples / fading | Novice learners | Demonstrate reasoning, gradually remove prompts |
| Elaboration / concrete examples | Abstract content | Ask why/how; use diverse concrete cases without overgeneralizing |
| Dual coding / cognitive load | Dense material | Integrate clear, purposeful visuals; avoid decorative distractions |
| UDL 3.0 | Accessibility/inclusion | Multiple means of engagement, representation, action and expression |
| Socratic discussion | Conceptual disagreement | Questions, counterexamples, evidence and reflection |
| Flipped classroom | Prepared learners | Pre-class independent work + in-class application and feedback |

## Decision by course type
- Programming / data structures: Merrill + worked examples + debugging misconceptions + executable labs + spaced retrieval + authentic project.
- Math: prerequisite dependency, worked solution, conceptual counterexample, graduated problems and proofs when relevant.
- Natural sciences: 5E inquiry where suitable, prediction -> evidence -> explanation, lab safety and data analysis.
- Humanities: primary-source critical reading, evidence-based argument, comparative interpretation; never invent historical quotes.
- Languages: comprehensible input, production, corrective feedback, spaced vocabulary retrieval.
- Teacher training: lesson enactment, observation notes, peer feedback, reflective revision.

## Quality and cautions
- Methods are options, not universal prescriptions. Context, learner age, prior knowledge, disabilities, subject and available time change what fits.
- Do not claim that every named framework has identical evidence quality.
- Write observable learning objectives; avoid unassessable verbs without indicators.
- Prefer instructive feedback explaining errors, not grades alone.
- Differentiate support without lowering substantive expectations.
- Don't force multimodal output when plain text is more accessible.
